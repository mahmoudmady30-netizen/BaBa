# إزاي تضيف فيديو افتتاحية حقيقي (Pixar-style)

لو حصلت على فيديو متحرك حقيقي (من أنيماتور محترف، أو أداة AI بتعمل فيديو زي
Runway / Pika / Kling — تقدر تديها نفس الرسومات اللي بعتّهالي كـ reference
وتطلب منها تعمل فيديو قصير متحرك بيها)، اعمل بس الخطوة دي:

1. سمّي الفيديو بالظبط: `opening.mp4`
2. حطه في المسار ده: `app/src/main/assets/opening.mp4`
3. ابني الـ APK تاني (زي المعتاد عن طريق GitHub Actions أو Android Studio).

التطبيق هيكتشف الفيديو أوتوماتيك ويشغّله كافتتاحية بدل الصور، من غير أي
تعديل في الكود. مهم: خلي الفيديو نفسه فيه الصوت جواه (لو فيه صوت أو موسيقى)،
لأن التطبيق مش هيضيف صوت TTS فوق الفيديو — هيسيب صوت الفيديو الأصلي يشتغل
لوحده.

لو مفيش ملف `opening.mp4` موجود، التطبيق هيرجع تلقائيًا لتسلسل الصور
المتحركة (Ken Burns + جسيمات لامعة) اللي موجود دلوقتي.
